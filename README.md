# 丽江—香格里拉行程规划

一个面向丽江与香格里拉旅行场景的静态行程规划页面，整合每日时间安排、景点、美食、交通与实用提示，可直接在浏览器中查看。

## 项目内容

- `index.html`：丽江—香格里拉行程规划页面
- `prompt.md`：生成旅行规划页面时使用的设计提示词

## 页面功能

- 按天展示旅行时间表
- 提供丽江古城、香格里拉等目的地行程安排
- 展示景点间交通方式与预计耗时
- 提供当地特色餐饮推荐
- 汇总住宿、出行和旅行注意事项
- 使用响应式卡片布局呈现信息

## 使用方式

直接使用浏览器打开 `index.html` 即可。

也可以在项目目录启动本地服务：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 数据说明

页面中的行程时间、交通耗时、门票、餐厅及营业信息属于旅行规划示例。实际出行前请通过官方渠道核对天气、交通班次、票务政策和营业状态。

## 项目亮点

- 将旅行需求拆解为行程、交通、餐饮和实用信息模块
- 使用结构化提示词辅助生成旅行产品原型
- 将复杂旅行信息整理为易浏览的日程页面
- 可继续扩展地图路线、POI推荐、天气接口和AI行程助手能力
